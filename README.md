# HimiLab (ХимиЛаб) 🧪

HimiLab is an interactive, web-based virtual chemistry laboratory and educational platform designed primarily for students in grades 5–10. It provides an engaging, safe, and highly visual digital classroom environment where users can explore chemical concepts, perform simulated experiments, and study environmental topics.

---

## 🚀 Key Features

- **Virtual Laboratory:** Run chemistry simulations using interactive reagents, test tubes, indicators, and burners without any real-world safety hazards.
- **Interactive Periodic Table:** A dynamic reference tool providing essential elemental data, properties, and electron configurations at a glance.
- **Ecology & Environmental Modules:** Educational pathways focused on green chemistry, eco-awareness, and real-world sustainability challenges.
- **Prof. Reaktiv (Проф. Реактив) AI Assistant:** An integrated virtual chemistry companion designed to guide students through experimental setups, explain complex bonding, and provide instant contextual feedback.

---

## 🛠️ Tech Stack

HimiLab is engineered to be a lightweight, fast, and accessible web application utilizing:
- **HTML5:** Semantic architecture for structured lab equipment layouts, navigation, and core modules.
- **CSS3:** Modern, responsive design featuring intuitive grids, animations, and clean interactive user interfaces.
- **JavaScript (ES6+):** Vanilla script handling the core simulation logic, dynamic state rendering for reactions, and AI assistant prompt interactions.
